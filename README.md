# Exclusivo Stars — Minimal Android

Cliente Android nativo mínimo para probar la compilación en NanoIDE.

- Kotlin
- Android Views + XML
- Sin Jetpack Compose
- Sin Retrofit/OkHttp/DataStore
- Sin librerías runtime externas
- Login visual local
- Preparado para añadir JSON/API después

Compilación: NanoIDE → Build Android APK → assembleDebug.

Primero hay que conseguir que este APK mínimo compile e instale. Luego añadiremos la arquitectura de red y sesión.
